📊 SPREADSHEET KERTAS KERJA -

Satu OPD memiliki satu Google Spreadsheet Kertas Kerja untuk setiap tahun. Di dalam satu file tersebut tetap terdapat seluruh sheet KK sesuai workbook template. Website hanya menyimpan ID dan link spreadsheet, sehingga workbook tidak lagi dimuat/dirender di halaman ini.
Template workbook dikendalikan oleh backend. Setiap OPD dibuat sebagai salinan satu file Google Spreadsheet, bukan satu file per sheet.

📁 EVIDENCE RTP -

Tentukan nama folder Evidence RTP. Folder akan digunakan untuk penyimpanan file pada R2 dan Google Drive berdasarkan OPD dan tahun aktif.
Folder tujuan: Evidence RTP
